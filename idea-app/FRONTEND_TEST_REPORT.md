- **启用 gzip 压缩**（Nginx 配置）：

#### 4.1.3 Nginx gzip 压缩配置

检查并启用 Nginx gzip 压缩（可能未启用）：

```bash
# 检查当前 gzip 配置

# 建议在 nginx.conf http 块中添加：
gzip on;
gzip_vary on;
gzip_min_length 1000;
gzip_types
    text/plain
    text/css
    application/javascript
    application/json
    application/wasm
    font/woff2;
```

### 附录 C：Flutter Web CanvasKit 交互限制说明

Flutter Web 默认使用 CanvasKit 渲染器，将 UI 绘制在 `<canvas>` 元素上，而非生成原生 DOM 元素。这导致：

1. **DOM 自动化工具无法操作**：Selenium、Playwright 等基于 DOM 的工具无法点击/输入画布内元素
2. **可访问性受限**：屏幕阅读器可能无法正确读取画布内容
3. **解决方案**：
   - 使用 Flutter integration_test 框架（直接操作 Flutter Widget）
   - 或使用 `--web-renderer html` 构建 DOM 版本（功能略有限制）
